# Documentación del proyecto DocuFlow (CONTABILIDADCQ)

Estructura de la documentación:

| Carpeta | Contenido |
|---|---|
| `guias/` | Guías paso a paso de operación y desarrollo (ngrok, pruebas locales, etc.) |
| `informes/` | Informes técnicos puntuales (optimización EC2, diagnósticos) |
| `migraciones/` | Bitácoras de migraciones de infraestructura (⚠️ pueden contener credenciales — están en `.gitignore`) |
| `deploy/` | Notas y checklists de despliegues específicos |
| `planes/` | Planes de implementación de funcionalidades |

## Documentos que viven FUERA de esta carpeta (por convención)

- `backend/agents.md` — reglas del proyecto backend para agentes de IA
- `frontend/AGENTS.md` — reglas del proyecto frontend para agentes de IA
- `frontend/README.md` — readme del frontend
- `informes/` (raíz) — exportes de negocio en Excel (no es documentación)
